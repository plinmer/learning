# 腾讯控股估值备忘录｜主营DCF与折价投资（2025年末）

> **口径与结论**｜以截至 **2025 年 12 月 31 日**的完整财年数据为依据，不使用2026年经营数据。基准假设下，腾讯并表主营业务约值 **3.66 万亿港元／402 港元每股**；加上折价后的未并表对外投资，合计约 **4.46 万亿港元／489 港元每股**；若另将披露的净现金全额计入，约 **4.58 万亿港元／502 港元每股**。这是情景估算，不是财报披露的公允价值或投资建议。

## 一、估值范围：先看经营，再看持股

- **主营业务**：腾讯已并表的游戏、社交及数字内容、广告、支付／金融科技、云及企业服务。收购后已并表的游戏公司也属于这一侧；只估合计经营现金流，不按收入比例捏造各业务自由现金流。
- **非主营资产**：腾讯持有、但未并表的其他公司股权。将其视为有折价的**存量资产**，不预测投资收益、不对会计投资收益做第二遍 DCF；它们不是真正的现金。
- **净现金**：在股权投资以外**单独列示**。需要判断多少属于可分配的超额现金，而非机械视为全额可取走。

因此，估值架构为：**经营现金流折现价值＋未并表持股的折价可实现价值＋可分配净现金**。关键约束是避免重复计算：若经营自由现金流中包含对外投资分红等现金收入，应先剔除，或在投资模块作对应调整。

## 二、主营业务现金流基数

腾讯公布的是**集团自由现金流**，不是单独命名披露的“纯主营、归母自由现金流”，也没有按游戏、广告、支付、云分别披露自由现金流。这里用集团指标作为并表主营现金创造能力的**代理值**；该指标从经营现金流出发，并扣除资本开支付款、媒体内容付款及租赁负债付款等。买卖外部股权的款项不直接作为经营自由现金流。\[1\]\[2]

| 完整财年               | 腾讯披露的自由现金流，统一按固定汇率折算 | 观察                                     |
| ------------------ | -------------------: | -------------------------------------- |
| 2023               |      约 **1,849 亿港元** | 现金流恢复，起点偏高                             |
| 2024               |      约 **1,719 亿港元** | AI 等投入增加，全年资本开支同比增长 221%，自由现金流同比下降约 7% |
| 2025               |      约 **2,022 亿港元** | 自由现金流同比增长约 18%                         |
| **2023—2025 三年均值** |    **约 1,863 亿港元／年** | **本模型的 DCF 起点**                        |

**为什么用三年均值，不只用2025年？** 三年均值可以平滑资本开支与营运资金的年度波动；直接以2025年单年起算会提高估值。2024年AI相关投入确实压制自由现金流，但不能把全部新增资本开支都认作一次性，也不能直接加回。\[1\]\[2\]\[3]

## 三、增长假设与 DCF 过程

腾讯2016—2025年的披露自由现金流起止值对应年复合增长约 **14.3%**（相隔9年），但这一阶段包含较早期高速发展，且2019—2020年前后统计口径有调整；2020—2025年约 **8.1%**，2023—2025年约 **4.6%**。\[1\]\[2\]\[4] 历史数据给8%假设提供讨论基础，**不能证明未来十年一定维持8%**。

| 参数          |              基准选择 | 性质                  |
| ----------- | ----------------: | ------------------- |
| 现金流起点       | 约 **1,863 亿港元／年** | 2023—2025年三年平均，自行计算 |
| 预测期         |           **10年** | 2026—2035年，模型假设     |
| 预测期自由现金流年增长 |            **8%** | 情景假设；并非公司指引         |
| 折现率         |           **10%** | 投资机会成本假设            |
| 此后永续增长      |            **2%** | 成熟期假设，要求低于折现率       |

计算公式：

```text
经营价值 = Σ[t=1…10] {起始现金流 × (1＋8%)^t ÷ (1＋10%)^t}
         ＋ [第10年现金流 × (1＋2%) ÷ (10%－2%)] ÷ (1＋10%)^10
```

| 主营 DCF 的组成 |                       折现价值 |
| ---------- | -------------------------: |
| 未来十年自由现金流  |            约 **1.69 万亿港元** |
| 第十年后永续现金流  |            约 **1.98 万亿港元** |
| **主营业务合计** | **约 3.66 万亿港元，约 402 港元／股** |

永续部分约占主营估值的 **54%**，因此估值对长期假设尤其敏感。例如保持8%预测期增长和2%永续增长不变，折现率由10%提高到11%，主营估值降至约 **352 港元／股**；降至9%，则约 **466 港元／股**。

**与之前两个数字如何对应？** 在相同的8%增长假设下，以2025年单年现金流作起点，主营估值约 **436 港元／股**；以三年均值作起点则约 **402 港元／股**。本文为保持基数平滑，统一采用后者。此前的约323港元／股，则是“三年均值起点＋未来十年增长5%”的另一情景，不能混用。

## 四、未并表持股：折价后一次性加入

腾讯2025年末披露的**上市投资公司持股公允价值**，折合约 **7,448 亿港元**；**非上市投资公司持股账面价值**，折合约 **4,020 亿港元**，两项均**不含附属公司**。[2] 上市部分受股价波动影响，非上市部分的账面价值不等于立即可实现售价。

| 持股类别      |          披露金额折算 | 本文折价假设 |                    纳入估值 |
| --------- | --------------: | -----: | ----------------------: |
| 上市被投公司持股  | 约 **7,448 亿港元** | **8折** |         约 **5,959 亿港元** |
| 非上市被投公司持股 | 约 **4,020 亿港元** | **5折** |         约 **2,010 亿港元** |
| **折价后合计** |               — | 主观情景假设 | **约 7,968 亿港元／87 港元每股** |

折价是为了给税费、市场波动、出售限制、流动性以及非上市估值不确定性留余地，**不是腾讯承诺的变现价格**。这里既不把持股当真现金，也不对过去的投资组合会计收益求平均并进行永续 DCF。

## 五、估值加总与使用边界

| 价值模块         |              估值 |         每股贡献 |
| ------------ | --------------: | -----------: |
| 并表主营业务 DCF   | 约 **3.66 万亿港元** | **约 402 港元** |
| 未并表投资折价价值    | 约 **0.80 万亿港元** |  **约 87 港元** |
| **主营＋折价投资**  | **约 4.46 万亿港元** | **约 489 港元** |
| 披露净现金若全额加入   | 约 **0.12 万亿港元** |  **约 13 港元** |
| **上述项目全部合计** | **约 4.58 万亿港元** | **约 502 港元** |

每股按**2025年末已发行、扣除库存股后约91.20亿股**计算。[5] 为便于统一比较，所有财报原币数据都按**2025年12月31日的固定汇率**折算为港币，而不是采用每一年的历史汇率；故早年的港币值仅供同口径测算，并非当年财报原值。[6]

### 必须检验的三个问题

1. **8%的增长能否变成扣除持续AI／云资本开支后的现金？** 业务收入和经营现金流增长不等于自由现金流同步增长。若投入长期持续，不应把它全部加回。\[2\]\[3]
2. **对外投资与主营现金流有没有交叉？** 集团自由现金流尚未逐项校准外部持股分红、少数股东份额及资金利息。402与87相加是透明的粗估，不是已审计的“纯主营归母＋可变现投资”精确值。
3. **净现金是否全额可分配？** 披露净现金已是现金减去相关债务的净额；既不能再单独加总现金，也不能再把同一笔债务重复扣除。为保守展示，本文把它放在最后单列。[2]

> **便于转述的结论：**“以2025年末为截面，我把腾讯并表业务的三年平均自由现金流作为起点，假设未来十年增长8%、折现率10%、永续增长2%，得到主营业务约402港元／股。未并表对外持股分别按上市8折、非上市5折计入，约增加87港元／股；再考虑全部净现金约增加13港元／股。于是整体粗估为约489—502港元／股。关键风险是未来持续资本开支、折现率与投资资产折价，而非一个精确目标价。”

## 六、AI高投入期：调整前3年现金流增速

上文主营402港元／股来自2026—2035年每年增长8%的平滑模型。为反映前期AI建设的现金支出压力，仅把2026—2028年的自由现金流增长率调低，其他条件不变：2023—2025年平均现金流折合约1,863亿港元／年、折现率10%、2036年起永续增长2%、2025年末约91.20亿股。以下增速均为情景假设，并非公司预测。

| **情景**   | **2026—2028** | **2029—2035** | **主营DCF** | **加折价投资** | **再加净现金** |
| -------- | ------------- | ------------- | --------- | --------- | --------- |
| 原平滑增长    | 8%            | 8%            | 402       | 489       | 502       |
| 过渡情景（采用） | 3%            | 8%            | 351       | 438       | 451       |
| 较缓和压力    | 5%            | 8%            | 371       | 458       | 471       |
| 零增长压力    | 0%            | 8%            | 323       | 410       | 423       |

单位：**港元／股**。对外投资与净现金继续按2025年末静态估算，分别约87、13港元／股；不是未来资产余额预测。

> **采用的过渡情景：**&#x524D;三年增长3%、后七年增长8%，主营DCF前十年现值约1.49万亿港元，终值现值约1.72万亿港元，合计约3.20万亿港元，即**351港元／股**；加折价投资约**438港元／股**，若再全额计入净现金约**451港元／股**。相比原平滑模型402港元／股，主营估值降低约51港元／股。

**风险边界：**&#x8FD9;一3%情景仍假设前三年每年正增长，并未模拟现金流负增长；AI投入回落也不保证2028年现金流自动改善。如果实际支出更高或商业化更慢，估值可能继续下修。2026年已披露信息只用于识别压力，不纳入2025年历史基数或资产截面。详见来源\[7\]\[8]。
